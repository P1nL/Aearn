## 三、按问题查文档

- **消息如何形成教学回合、何时提交结果？** 先读运行时文档，再对照 API 中的回合、快照与 SSE 契约。
- **断线重连、重复提交、后台续接如何处理？** 联读 API 的游标与幂等规则、数据库的状态与凭据，以及运行时的续接规则。
- **各类学习产物的结果是否相同？** 查看当前文档中练习、知识检查、模型代码审查与 SQL 的提交、结果和评分边界，不直接套用早期代码补全方案。
- **复习或课程进度由谁更新？** 查看当前运行时与数据库文档中的课程轨道、复习会话及服务端状态，不依据前端展示或历史 FSRS 表名判断。
- **现在能否发布或上线？** 查看 [发布就绪记录](../qa/tutor-harness-release-readiness.md) 和 [验收测试计划](../qa/acceptance-test-plan.md)，架构说明本身不构成发布许可。
- **如何启动本地环境？** 查看 [开发环境指南](../setup/development-environment.md)，不要从历史迁移章节拼接启动步骤。

## 四、术语与表达约定

| 术语 | 中文阅读方式 |
| --- | --- |
| Tutor Harness | Tutor 运行与治理框架；保留项目正式名称 |
| authority | 权威状态或最终裁决来源，不泛指访问权限 |
| receipt | 持久化凭据；具体追溯、幂等或确认作用以对应契约为准 |
| projection | 面向指定用途的状态投影，不是另一套独立状态机 |
| admission | 请求或任务准入，不等于执行完成或业务成功 |
| cutover | 受控切换；涉及历史数据时须同时阅读删除与回滚边界 |
| Artifact / Learning Item | 学习产物 / 学习条目；协议标识符保留原文 |
| Track / TeachingSession / Turn | 课程轨道 / 教学会话 / 回合；不混淆不同范围的状态 |

标题、说明、表头以中文为主；API 路径、字段名、枚举、版本、文件路径及命令保留原文。历史提示词和代码样例不因翻译改变协议含义。

## 五、维护与验证边界

1. 更新运行时行为时，同步检查 API 与持久化说明；只在所属文档定义详细契约，其余文档通过链接引用。
2. 当前事实以实际路由注册、类型与校验、数据库片段清单、配置和测试为核查依据；测试文件存在不等于测试已运行。
3. 分别记录“当前源码实现”“历史执行结果”“本次实际验证”“规划或待验证能力”，不得互相替代。
4. 保留旧章节链接与历史日期；旧规格不得以无说明的删除或覆盖方式消失。
5. 文档核查不替代真实模型、数据库、浏览器、执行容器或生产迁移验收，也不自动授权提交、推送、部署或发布。
