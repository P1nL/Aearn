# Aearn

Aearn 是面向 AI 编程的编程语言学习 Agent。正式产品实现位于 `aearn/`，产品与技术规格以 `docs/` 中的权威文档为准。

## 从这里开始

- [运行工作区](aearn/README.md)：依赖管理、运行目录和常用开发命令。
- [文档索引](docs/README.md)：产品流程、架构、API、数据库、环境配置与验收依据。
- [协作规则](AGENTS.md)：仓库约定和 Agent 工作规范。

## 目录导航

| 路径 | 用途 |
| --- | --- |
| `aearn/` | 桌面端、API、worker、executor、共享契约与基础设施。 |
| `docs/` | 权威规格、开发指南、验收记录、设计原型和历史文档。 |
| `scripts/smoke/` | 独立冒烟验证脚本；运行前查看脚本与相关操作指南。 |
| `.trellis/` | 开发流程、编码规范、任务记录和协作日志。 |
| `.agents/`、`.codex/`、`.claude/` | Agent 技能、工具配置与平台协作入口。 |
| `tmp/` | 已被 Git 忽略的本地临时材料，不作为项目依赖或规格来源。 |

新增业务代码放入 `aearn/` 对应模块；根目录保留仓库导航、Git、Trellis、文档和 Agent 配置。历史教程目录不作为当前运行环境或依赖来源。
