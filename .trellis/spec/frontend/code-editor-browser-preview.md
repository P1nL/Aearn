## 3. Contracts

- Monaco 是单文件、lazy load、按 conversation + Artifact identity/version 建 model path；draft、cursor、view state 和 scroll 只保留在当前 Desktop 进程，authoritative version refresh 不覆盖当前 learner draft。
- 新工件滚动到 shell 但不 focus Monaco。终态或 `editable=false` 时编辑器只读；不提供文件树、终端、依赖安装、真实路径或包管理器。
- Preview 对 draft 做 400ms debounce 并自动更新，但不创建 Attempt、不完成任务。只有 learner 显式点击 Run 才把当前 exact source 发送给 Artifact action API。
- Run 成功后记录当前进程内 source baseline；之后编辑立即显示 stale。score、pass、Attempt、result 和 completion 仍完全来自服务器。
- 宽容器固定 50:50 Editor/Preview；窄容器固定上下等分，不提供 draggable splitter。resize/scroll 只更新 native bounds，不重建 Monaco model。
- Learner source 永不进入 main DOM、`dangerouslySetInnerHTML`、main iframe 或 A3a fallback。Preview unavailable 时显示稳定 unavailable 状态。
- Preview 使用 app-owned `CustomProtocol`、独立 child webview、incognito/dedicated data directory、sandboxed learner iframe 和 response CSP。top-level navigation、new window、download、network/connect、form、object、parent control 与 Tauri command authority默认拒绝。
- `capabilities/default.json` 必须只匹配 `webviews:["main"]`，不得使用 `windows:["main"]` 或可匹配 `aearn-preview-*` 的 glob；Preview label 不匹配任何 capability。自定义 Preview commands 还必须通过 `build.rs` 的 `AppManifest::commands` 进入 ACL，并只把 autogenerated `allow-preview-host-*` permissions授予 main；每个 command继续用 `require_main_webview` 做二次校验。
- WebView2 learner subframe 可能仍可观察到不可配置的 `__TAURI_INTERNALS__` 对象；完成门是“无可调用 authority”而不是只做对象缺失断言：Preview CSP 单独阻断 network/connect，而 Tauri IPC authority 必须由 child capability缺失、app-command ACL与 command caller guard共同拒绝。
- 创建 child webview 的 command 必须是 async；不得从 Windows 同步 command/event handler 创建。
- Source update 旋转 generation/nonce。Rust bridge exact 校验 host/source Artifact、TeachingSession、Artifact version、generation、nonce 和递增 sequence；未知/extra/oversized/replay 事件丢弃。
- Bridge 只接受 `ready | console | runtime_error | interaction_event`；message 最多 1024 Unicode scalar，event key 最多 160 stable characters，console 最多保留 40 项。
- `ready` heartbeat 必须从 learner iframe 的 event loop 发出，而不是 host page timer。无限循环阻塞 learner frame 后 heartbeat 停止；main WebView watchdog 只重建 Preview host，保留 editor、Composer、timeline 与 draft。每次 recreate必须轮换 generation-specific WebView2 data directory，避免复用被 hang renderer 的 environment；同一 source自动重建最多一次，仍无 heartbeat则隐藏 child并进入 `PREVIEW_HOST_UNRESPONSIVE`，只有显式 reload或新 source才重置预算。

## 4. Validation & Error Matrix

| Condition | Required behavior |
| --- | --- |
| Web target / non-Tauri | `PREVIEW_HOST_UNAVAILABLE`; no iframe/main-DOM execution fallback |
| nonce/scope/version/generation mismatch or replay | Rust/TypeScript boundary rejects event/update |
| source hash mismatch or source > 48,000 chars | native command rejects before navigation |
| external navigation/popup/download/form/network | native handler, sandbox or CSP denies |
| heartbeat absent for 2.8s | recreate Preview only, rotate nonce/generation/data directory once; repeated hang -> hide child + `PREVIEW_HOST_UNRESPONSIVE` |
| source edited after run | old result remains visibly stale |
| terminal Artifact | Monaco read-only; no executable Run |

## 5. Tests Required

- Rust tests: exact capability targeting, `CustomProtocol`, sandbox/CSP source encoding, navigation deny, nonce/scope/version/replay/oversize rejection, source hash/bounds, learner-frame heartbeat placement.
- Vitest: latest-draft explicit Run, stale/read-only/model carry-forward/no focus, strict event parser, debounce, resize bounds, mismatch ignore, watchdog recreate, unmount close.
- Full Desktop Vitest, `pnpm --dir .\aearn desktop:check`, `cargo test`, `cargo check`, task validation and `git diff --check`.
- Native visual/security smoke uses a disposable env/query-gated Tauri fixture and `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` CDP when available. If the dedicated child environment is not exposed as a CDP target, record the exact target list and combine main-DOM/bridge behavior, app-command mismatch probes, native deny handlers, download-file absence, hang/recovery, and Rust tests; web-only Vite evidence仍只证明 unavailable fallback。
