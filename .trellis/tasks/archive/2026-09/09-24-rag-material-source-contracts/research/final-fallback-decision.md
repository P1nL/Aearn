# 最终决策与实施验收路由

日期：2026-09-24。状态：规划定稿核对，非已实现行为。

## 最新用户决定（覆盖旧选型建议）

1. 课程材料完整性优先，完整相对于已确认课程目标；不为节省搜索而静默删目标或放宽核验。
2. 优先已审核知识库，缺口使用Tavily免费档；额度耗尽仅使用已有知识库教材兜底，不启用模型原生联网、不新增搜索provider。
3. 已有知识库指实际可读、版本适用且用途获准的材料，不是模型记忆、seed URLs、fixture演示或尚未准入的搜索结果。
4. 可以重组解释/示例并保留来源绑定。不能补足的部分保持gap；部分单元ready不代表全课程ready，且继续教学必须满足课程前置依赖；正式评分与Gate另验。
5. 无自动付费、账户注册/绑卡、模型更换或部署。Tavily密钥仅主代理真实验证时读取；子代理用离线fixture。

## 交付拆分

- A：纯合同、受信server context、用途/版本/权限判定与默认关闭；不写provider SDK、真实预算台账、schema、worker或公开consumer。需要在合同中容纳材料覆盖与来源状态，不伪装运行时已经生效。
- B1：Tavily受控适配与持久化预算，归一化可恢复错误；额度耗尽输出existing_only路由信号。鉴权错误/普通限流/超时不谎报额度耗尽；不自动重试未知消费。
- C：教材审核/用途及真实来源池。库存不够仍是产品事实，不用种子注册数冒充教材数量。
- D：消费existing_only，只检索符合条件的已存教材；冻结binding，报告每单元及课程覆盖，检查前置依赖。无需新联网模型。
- E：真实Tavily成功与受控额度耗尽模拟分开标识；不为测试主动耗尽1000额度。覆盖准入/绑定/题库consumer分别给证据。

## 最小验收矩阵（未来实现）

| 场景 | 预期 |
| --- | --- |
| 已有教材充分 | 不搜索，来源/版本/用途绑定准确 |
| 有缺口且额度充足 | Tavily受控发现，不直接准入 |
| 配额耗尽、知识库可补足 | existing_only，新增外部发现调用为0 |
| 空库/seed-only/错版本/撤权/错用途 | 保留gap，不伪造教材或ready |
| 部分单元有材料但前置缺失 | 不越过依赖，其他独立就绪单元可继续 |
| 超时/401/429等错误 | 正确区分原因，不伪造quota_exhausted；未知消费保留 |
| 账户快照滞后/并发/重启 | 真实费用不丢失，预算不重置 |
| 搜索关闭或无可信预算上下文 | 无外部调用，已有材料仍依合法权限读取 |

以上为测试要求，不是测试已通过。当前保持planning，无业务代码变更；不得把本文件当作task start或发布许可。
