# 已确认的产品与 UI/UX 决策

## 范围

纳入：A1 对话内工件、A2 Monaco、A3b 真实交互预览、A4 执行结果、A6 结构化检查、A7 多级提示、A8 AI 代码审查、A9 SQL、A10 来源引用，以及必须的 artifact/SSE/teaching/item-bank 基础。

不纳入：A3a 伪预览、独立大型成绩证据仪表盘、进度卡、服务器草稿历史、多文件 IDE、终端、包管理器、复杂模拟器。

## 对话内工件

- 所有任务、编辑、预览、运行、检查、提示、审查和 SQL 操作都在 Tutor 对话流中。
- 右侧区域继续作为文档与来源阅读区。
- Artifact 与普通聊天明显区分，但界面简洁、没有冗余小字说明。
- 新工件自动展开并滚动到工件位置；键盘焦点保持原状。
- 工件完成后保持展开，直到用户发送下一条消息；当前程序运行期间保留 UI 状态，重新打开会话时从服务器重新加载。
- 宽屏编辑器/预览左右固定等分，窄屏上下固定分屏，不允许用户拖动比例。
- D1-D5 基础难度以低存在感 `D(n)` 放在工件角落。

## Markdown

- Tutor 消息、任务说明、提示、评价和安全反馈支持 Markdown。
- 支持受控字号和颜色扩展；禁止任意 raw HTML/CSS/script。
- 字号有上下界，颜色必须格式合法并满足可读对比度。
- 支持流式增量 Markdown、代码块、高亮、表格、引用和复制。

## 代码与执行

- 编辑器和 Browser Preview 实时联动；Preview 不产生 Attempt、不改变掌握度。
- Run 必须由用户显式触发；不自动运行、不自动提交。
- Run 全部通过后直接完成，无第二个 Submit 动作。
- 每次 Run 完成后，Tutor 新起主线 Turn：先输出 Markdown 评价，再输出服务端权威测试结果工件。
- 原代码工件显示编辑器和实时 Preview；测试结果工件显示总结果、失败项、必要位置、按需 stdout/stderr、SQL grid 和返回修改。
- 通过项在失败结果中合并为“其他 N 项通过”；隐藏测试不泄漏 ID、输入或答案。

## 演示

- 演示代码只读，用户不能修改；交互 Preview 可操作。
- 可交互演示等待 exact 预期事件后结束。
- 静态演示按有效可见时间结束；底部用 2-3px 细进度动画表示时间。
- 展示时间课程配置优先，系统按内容量计算兜底，建议 6-30 秒；模型不能设置。
- 只有应用前台、会话打开、内容可见时计时；用户消息优先于自动继续。

## 结构化检查与提示

- 回答提交后固定，不允许修改；模型新起消息评价并输出权威结果。
- 答错后创建新补救工件，不在原题反复猜。
- 概念题第一次错误只解释误区并给一次补救；同知识点第二次错误直接讲解答案并创建迁移检查。
- 简单事实题可在第一次错误后直接解释；用户主动索要答案时不得拒绝，但记录 direct-answer assistance。
- 同一知识点最多原题 + 一次补救，禁止无限猜题。
- Hint 使用 H1 方向、H2 概念、H3 结构；直接答案不属于普通提示页。
- Hint 在原工件表面上的 overlay popover 内展示，不参与布局；多级提示手动横向分页、按页首次查看记录 receipt，不自动轮播。

## AI 代码审查

- 聚焦可验证的 AI 常见错误：需求偏离、编造 API/假设、逻辑与边界、契约集成、异步状态生命周期、安全信任边界、错误处理/虚假成功；弱测试作为专题扩展。
- 可读性、维护性和风格只作为 Tutor 非评分建议，除非违反明确项目规范。
- 用户选择代码范围、错误类别并写简短说明；原审查完成后锁定，Tutor 新消息输出评价和结果。

## SQL

- 宽屏 SQL editor 与 Schema 左右固定分屏，窄屏上下排列；结果表格放在原 SQL 工件底部。
- SQL 不实时执行，只在用户点击 Run 后执行。
- 原工件底部是公开查询数据；Tutor 新消息中的结果工件是权威测试评价。
- Schema 显示表、列、类型、PK/FK 和关系；示例数据按题目需要提供。
- 表名、列名和限定名可复制，但不自动插入编辑器。

## 来源文档

- 点击引用后右侧文档栏打开，滚动到稳定 block，并用不引发布局变化的虚线框动画突出目标。
- 窄屏从右侧覆盖对话区域大部分，用户点击“收起”关闭；点击外部不自动关闭。
- 对话滚动、Artifact 状态和编辑器状态保持不变。

## 答疑支线

- 等待交互时 Composer 始终可用。
- 普通用户消息进入锚定当前工件的单层临时答疑支线；用户气泡仍右对齐，Tutor 左对齐，整组由左侧分支线包裹。
- 工件动作和教学控制返回主线；支线不能嵌套或创建第二个交互工件。
- 主线恢复后支线自动折叠成“答疑 · N 轮”，可手动展开。
- 无关问题也进入临时支线；模型先回答，再引导用户专注当前主线。明确切换主题属于教学控制，需要确认暂停当前任务。

## 题库与审核

- 采用 versioned Learning Item Bank，而不是在线临时出题。
- 人工定义知识点/蓝图/发布规则，AI 生成 draft，机器验证，子代理独立审核，Pilot 后发布。
- 风险分级：低风险可自动 Pilot/晋级；中风险需机器执行 + 教学/技术/安全/对抗审核并由 Pilot 数据晋级；高风险最终人工批准。
- 生成代理不能审核自己的题；安全、唯一答案、执行失败和泄漏问题一票阻断。
