# 练习卡片 UI 优化 — 技术设计

## 概述

重构 ExerciseWorkbench 的渲染层和样式，不改变 props 接口和数据流。核心变化是将当前的"线性堆叠两栏"改为"固定高度左右分栏 + 右栏独立滚动"，并为代码编辑器引入暗色主题。

## 影响范围

| 文件 | 变更类型 |
|------|----------|
| `features/learning/ExerciseWorkbench.tsx` | JSX 结构重组 |
| `features/learning/CodeEditor.tsx` | Monaco 主题参数 |
| `styles.css` (exercise 相关块) | 布局 + 视觉样式重写 |

不涉及：props 接口、数据流、API 调用、类型定义、其他页面。

## 布局方案

```

├──────────────────────┬──────────────────────────────┤

│                      │                              │

│  ┌────────────────┐  │  └─────────────────────────┘ │
```

## 关键决策

### 1. Monaco 自定义深绿主题

不使用 `vs-dark`（蓝灰色调与项目不搭）。注册自定义主题 `aearn-dark`，色板基于项目变量：

| 用途 | 色值 | 来源 |
|------|------|------|
| 编辑器背景 | `#1a2b23` | --ink 加深 |
| 侧边栏/行号背景 | `#15201b` | --ink |
| 前景文字 | `#e4ece4` | --sidebar 反转 |
| 关键字高亮 | `#5cc9a0` | --accent 提亮 |
| 字符串 | `#b8d4a8` | 绿色系暖色 |
| 注释 | `#5e6b62` | --muted |
| 选中行背景 | `rgba(47, 125, 99, .15)` | --accent 透明 |
| 光标 | `#2f7d63` | --accent |

在 CodeEditor 组件中通过 `monaco.editor.defineTheme('aearn-dark', {...})` 注册，仅执行一次。编辑器容器外框使用 `border: 1px solid var(--line-strong)` + `border-radius: var(--radius-md)` 保持与项目卡片风格一致。

### 2. 右栏独立滚动

- 左栏：`overflow: visible`，高度由内容撑开（编辑器固定 `height: 360px`）
- 右栏：`overflow-y: auto; max-height: calc(100vh - 200px)`，内容超出时滚动
- 整体 grid 不设固定高度，由左栏自然高度决定

### 3. 辅助操作收纳

将"提示目标/层级 + 获取提示 + 解释错误"和"解释关键代码 + 检查焦点 + 检查解释"分别包裹在 `<details>` 折叠区中，默认收起。主操作（运行测试、提交）始终可见。

### 4. 响应式回退

`@media (max-width: 1180px)` 时：
- grid 回退为 `grid-template-columns: 1fr`
- 右栏取消 `max-height` 和 `overflow-y`
- 编辑器高度缩小为 `240px`

## 兼容性

- 不改变任何 prop 签名，父组件 LearningWorkspacePage 无需修改
- 不改变 DOM 事件绑定逻辑
- 不引入新依赖
